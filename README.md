# 💊 Pharma-Tech Founder Mentor

A single-file, interactive 24-month roadmap (React, runs in any browser) for a
B.Pharm student building AI tools for India's pharmaceutical MSMEs — and working
toward their own pharma manufacturing + export business.

Open `index.html` in a browser. Progress is saved locally.

## Roadmap structure

96 weeks across 5 phases:

1. **Foundations** (Months 1–3)
2. **Tech + AI Core** (Months 4–7)
3. **Business + Product** (Months 8–12)
4. **Launch Prep** (Months 13–18)
5. **Manufacturing + Export + AI Agents** (Months 19–24)

## Recent restructure

The roadmap was rebalanced to introduce high-leverage skills earlier:

- **AI coding assistants from Day 1** — GitHub Copilot + Claude Code (Week 2),
  Gemini CLI + an AI "learn-2x-faster" tutor loop (Week 3).
- **Real freelancing in Month 2** — Upwork/Fiverr setup (Week 7) and building
  websites for local pharma businesses to earn the first ₹5k–₹20k (Week 8).
- **Export business earlier (Month 3)** — COPP, Dossier, CTD/eCTD and export
  documentation mapped in Week 9 (building on WHO-GMP from Week 6).
- **Data analysis earlier (Month 3)** — Pandas + Excel automation (Week 10) and
  a first Power BI pharma dashboard (Week 12).
- **Manufacturing knowledge from Month 4** — production workflow + QA/QC
  (Week 13); HVAC, water systems, clean rooms and validation (Week 16).
- **Modern AI stack (Months 4–6)** — Ollama (Week 14), OpenRouter (Week 15),
  Vector Databases (Week 18) and MCP / Model Context Protocol (Week 20),
  alongside the existing LangChain/LangGraph track.
