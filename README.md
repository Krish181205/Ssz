# 💊 Pharma-Tech Founder Mentor

A single-file React app: a **24-month, week-by-week mentor roadmap** (96 weeks, 167 tasks, 1,070 micro-steps) for a B.Pharm student in India building a pharma-tech startup + export business.

**Open `pharma_mentor_fixed.html` in any browser — no install needed.** Progress auto-saves locally; the **💾 Save Backup / 📥 Restore** buttons export/import your progress as a file on your device.

The **⏱ Skill Investment Calculator** is built into the app (header button): daily hours/minutes/days sliders → live weekly/monthly/yearly totals, 10,000-hour mastery timeline, full-time-week equivalents, weekly time share. Optimised for Android (S25 Ultra class) and Windows 11 browsers.

## The 5 Phases

| Phase | Months | Focus |
|---|---|---|
| 1 — Foundations | 1–3 | Python (CS50P), SQL, USP GMP, WHO-GMP, Schedule M, GitHub + LinkedIn |
| 2 — Tech + AI Core | 4–7 | Prompt engineering, LangChain, RAG, AI agents, web scraping, customer discovery |
| 3 — Business + Product | 8–12 | YC Startup School, MVP, accounting + product costing, pilots, pitch deck |
| 4 — Launch Prep | 13–18 | Payments, sales, launch, fundraising, first hire |
| 5 — Manufacturing + Export + AI Agents | 19–24 | See below |

## Phase 5 skill pillars (Months 19–24)

1. **Manufacturing + GMP** — Schedule M plant requirements, WHO-GMP certification, validation (VMP/IQ/OQ/PQ, process + cleaning validation, MACO), documentation (SOP/BMR/BPR, ALCOA+), full tablet production workflow
2. **Regulatory Affairs** — CTD (all 5 modules), eCTD lifecycle, ACTD, CAPA, deviations, change control
3. **Export Business** — IEC/RCMC/AD-code setup, international market research (Trade Map), product registration abroad (COPP/FSC, Zone IVb), distributor acquisition, tender business (UNGM, GeM, national agencies), export documentation + INCOTERMS + LC
4. **AI Automation** — Python, n8n, APIs, web scraping; builds: **AI Export Agent** (find distributors, enrich contacts, draft emails, track follow-ups), **AI Tender Agent** (monitor tenders, alert opportunities, generate responses), **AI Regulatory Agent** (check documents, compare SOPs, generate compliance reports)
5. **Sales & Negotiation** — LinkedIn outreach system, cold email + deliverability, discovery calls (SPIN + MEDDIC), negotiation (price, payment terms, exclusivity)
6. **Finance** — product costing, full export costing model, working capital + cash conversion cycle, inventory control (ABC/EOQ/FEFO), 13-week cash flow forecast

Progress is saved locally per task. Each task includes: why it matters, numbered micro-steps, resources, time estimate, and a pro tip — plus an optional AI mentor for deeper guidance.
